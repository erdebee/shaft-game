# Mission layer

Empty by design. The mission layer sits between `shaft` and `event` in
`LAYER_ORDER` and exists for Chapter 3's episodic per-Shaft crises (failing
geothermal, rising groundwater, collapsed food chain, political fracture, the
abandoned Shaft).

Chapter 3 is vision only and excluded from v1 — see `concept/narrative-spine.md`.
The layer slot is reserved now so the resolver's order never has to change
later; nothing loads from here in v1.
