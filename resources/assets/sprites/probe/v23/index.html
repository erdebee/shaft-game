Light flicker: a dim version of every still room

The 29 rooms that are not animated each get a second image, <room>-dim.png, with the lamps about 17% dimmer. The game can swap a room's on image for its dim one at random moments, so the lights across the shaft flicker independently. There are no GIFs: each dim version is a plain, separate image.

How it's made (no generations used): every colour of the lit render is mapped to one darker colour. How much depends on the room's own off render: colours that go dark when the lamps are off (lamp glass, light pools, lit walls) dim the most; shadows barely change. The palette, dithering and every edge stay exactly as drawn, so switching between the two images changes only the light.

Rerun: python3 dim.py 0.3 in this folder (0.3 = about 17% darker; raise it for a deeper dip).

Flicker in this demo: each room waits a random 2–12 s, then blinks dim 1–3 times for 40–120 ms each. The seven animated rooms keep playing their loops.
